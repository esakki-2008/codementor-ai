# CodeMentor AI

Learn programming from zero. Understand every line.

CodeMentor AI is a beginner-focused programming learning platform. The first release focuses on Python fundamentals, guided lessons, practice questions, and clear explanations.

## Current MVP
- Responsive landing page
- Student dashboard with a Python learning roadmap
- Five interactive beginner lessons
- Multiple-choice knowledge checks
- Session-only lesson completion state

## Tech stack
- Next.js App Router
- React and TypeScript
- Tailwind CSS

## Run locally
\`\`\`bash
npm install
npm run dev
\`\`\`
Open http://localhost:3000.

## Project status
This is an early MVP. Authentication, persistent progress, a real AI tutor, and secure Python code execution are not implemented yet. Do not run arbitrary student code on the application server.

## Free-first development
The project is designed to be developed locally with free tools. Hosting, database, AI and code-execution services must be checked for current quotas and commercial-use terms before a paid public launch.
